# 🎮 Документация к голосовой аркадной игре

## 📌 Описание

Этот проект представляет собой голосовую аркадную игру, где игрок управляет персонажем с помощью голоса. Персонаж поднимается вверх при звуковой активности и опускается вниз при отсутствии голоса. Цель игры — собирать буквы, формируя заданное слово, и избегать пропуска нужных букв.

---

## ⚙️ Глобальные настройки

Перед запуском игры задаются основные параметры:

### Общие настройки
- **SCREEN_WIDTH**, **SCREEN_HEIGHT** – размер окна игры.
- **SCREEN_TITLE** – заголовок окна.
- **GAME_DURATION** – общее время игры (в секундах).

### Физика персонажа
- **UP_FORCE** – сила подъёма при голосе.
- **GRAVITY_FORCE** – сила гравитации.
- **MAX_UP_SPEED**, **MAX_DOWN_SPEED** – максимальные скорости подъёма и падения.
- **GROUND_Y**, **AIR_Y** – минимальная и максимальная высота движения персонажа.

### Параметры волн
- **WAVE_INTERVAL** – интервал между появлением новых волн.
- **WAVE_SIZE** – количество объектов в одной волне.
- **COLLECTION_TIME** – время сбора букв в одной волне.

### Анализ голоса
- **PITCH_FLOOR**, **PITCH_CEILING** – диапазон допустимых частот голоса.
- **SILENCE_THRESHOLD_DB** – минимальная громкость для распознавания.
- **VOICING_THRESHOLD** – порог вероятности голосового сигнала.
- **BLOCKS_TO_SILENT** – количество блоков тишины для определения отсутствия голоса.

### Файловые пути
- **ALPHABET_FOLDER** – папка с изображениями букв для гемов.

## 🖥️ Графический интерфейс настроек

Перед стартом игры появляется окно настроек (`GameConfigWindow`). В нём можно изменить:
- Интервал появления волн.
- Количество гемов в волне.
- Длительность игры.
- Время сбора букв.
- Целевое слово или букву.

После ввода настроек пользователь нажимает **"Запустить игру"**, и настройки обновляются.

## 🎤 Анализатор голоса

### `analyze_voice()`

Функция анализирует входящий аудиопоток:
1. **Читает аудиопоток** с микрофона.
2. **Извлекает параметры звука**: интенсивность (громкость) и высоту тона (pitch).
3. **Проверяет условия**:
   - Если громкость выше порога и частота попадает в допустимый диапазон – персонаж поднимается.
   - Если голос отсутствует несколько блоков подряд – персонаж падает.

Функция **генерирует** `1` при голосе и `0` при его отсутствии.

## 🕹️ Игровые классы

### 🌆 Фон (`ScrollingBackground`)
Создаёт эффект прокрутки заднего фона. 
- Два изображения чередуются, создавая эффект бесконечного движения.

### 👤 Персонаж (`PlayerCharacter`)
- Двигается вверх при обнаружении голоса.
- Падает вниз под действием гравитации.
- Меняет анимацию в зависимости от состояния (стояние, прыжок, падение, бег).

### 🔠 Объекты (`Gem`)
- Гем – объект, содержащий буквы, которые нужно собрать.
- Двигается влево с постоянной скоростью.
- Исчезает при сборе или выходе за пределы экрана.

## 🎮 Игровой процесс

### `VoiceArcadeGame`
Главный класс, управляющий всей игрой.

### Основные методы

#### `setup()`
- Загружает фон.
- Создаёт персонажа.
- Обнуляет счёт.
- Запускает первую волну объектов.

#### `on_draw()`
Отрисовывает:
- Фон.
- Персонажа.
- Гемы.
- Интерфейс (счёт, таймер, статус полёта).

#### `on_update(delta_time)`
- Проверяет, истекло ли время игры.
- Анализирует голос.
- Проверяет столкновения персонажа с объектами.
- Запускает новую волну при необходимости.

#### `start_new_wave()`
Запускает новую волну гемов с установленными параметрами.

#### `add_gem(delta_time)`
Добавляет один объект-гем.

---

## 💥 Столкновения и очки

- Если персонаж касается буквы, гем считается собранным.
- Если гем уходит за левый край экрана, он считается пропущенным.
- Очки начисляются за успешное прохождение волн.

## 🚀 Запуск игры

Финальная часть кода создаёт объект игры и запускает цикл `arcade.run()`:

```python
if __name__ == "__main__":
    game = VoiceArcadeGame()
    game.setup()
    arcade.run()
```

- **Создаётся экземпляр `VoiceArcadeGame`**.
- **Вызывается `setup()`** для подготовки игры.
- **Запускается `arcade.run()`**, который выполняет бесконечный цикл отрисовки и обновления.
