# Разбор кода `VoiceBowlingGame` на Python + Arcade

Этот файл содержит подробное объяснение кода игры **VoiceBowlingGame**, написанной с использованием библиотеки `arcade`. Основная идея игры — игрок произносит звук, и шар катится по дорожке, чтобы сбить кеглю.

---

## 📁 Импорты

```python
import arcade
import time
from pathlib import Path
from game.settings import SCREEN_WIDTH, SCREEN_HEIGHT, SCREEN_TITLE
from game.voice import analyze_voice
from game.sprite_pin import Keglya
```

### Объяснение:
- `arcade` — библиотека для 2D-графики и создания игр.
- `time` — для измерения времени движения шара.
- `Path` — используется для получения абсолютного пути к файлу шрифта.
- `game.settings` — содержит параметры окна (ширина, высота, заголовок).
- `game.voice` — содержит функцию `analyze_voice`, реагирующую на голос.
- `game.sprite_pin` — содержит класс `Keglya`, наследующий `arcade.Sprite`.

## 🎮 Класс `VoiceBowlingGame`

### Конструктор `__init__`

```python
def __init__(self, task=None):
```

Создаёт окно и инициализирует основные переменные:
- `self.task` — словарь с параметрами задания (`duration`, `text`).
- `self.player`, `self.ball`, `self.pins` — игровые объекты.
- `self.ball_speed` — скорость шара.
- `self.task_sprite` — надпись задания.
- `reset_game_state()` — сброс состояния движения (флаги, таймеры).

```python
def reset_game_state(self):
```

Обнуляет логические флаги:

## ⚙️ Метод `setup`

```python
def setup(self):
```

Основная инициализация игры:
- Устанавливает фон и текст задания.
- Создаёт спрайты игрока, шара и кегли.
- Вычисляет скорость шара из параметра `duration`.
- Запускает анализ голоса.

---

## 🎙️ Метод `on_voice_detected`

```python
def on_voice_detected(self, is_voiced):
```

Колбэк, вызываемый при изменении голосовой активности:
- Если голос **появился** — начинается движение шара.
- Если голос **пропал во время движения** — фиксируется ошибка и движение прерывается.

---

## 🖼 Метод `on_draw`


Рисует всё содержимое окна:

- Текст задания

- Кегли

Также считает и обновляет таймер движения (если активен).

---

## 🔁 Метод `on_update`

```python
def on_update(self, delta_time: float):
```

Обновляет состояние игры каждый кадр:
- Если ошибка (`failed_attempt`) — шар отклоняется и "падает".
- Если движение активное — шар катится вперёд.
- Проверяется столкновение с кеглей.
- При ударе игрок меняет позу.

---

## ⌨️ Метод `on_key_press`

```python
def on_key_press(self, key, modifiers):
```

Перезапускает игру при нажатии клавиши `R`.

---

## 🧠 Логика игры (в упрощённом виде)

| Событие                    | Результат                                             |
|----------------------------|--------------------------------------------------------|
| Игрок говорит              | Шар начинает катиться                                 |
| Игрок молчит слишком рано | Шар падает и катится по диагонали (ошибка)            |
| Шар доезжает до цели       | Игра замораживается                                   |
| Столкновение с кеглей      | Кегля "сбита", игрок меняет позу                      |
| Нажата клавиша `R`         | Игра полностью перезапускается                        |
